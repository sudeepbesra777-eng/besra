## 3. EXACT PROMPTS

### THE STYLE LOCK — paste this at the end of **every** image and video prompt
Do not edit it once you have started. It is the only thing making 30 shots look like one video.

```
Stylized 3D scientific visualization, deliberately not photorealistic and not archival
documentary footage. Cold desaturated palette limited to bone white, glacial teal, and deep
navy black. Volumetric light, soft atmospheric haze, fine film grain. Cinematic widescreen
16:9 framing, shallow depth of field. No people, no faces, no hands, no text, no letters,
no numbers, no logos, no watermarks.
```

**Two rules that come with it:**
- **Non-photoreal on purpose.** This is a real expedition. Photoreal AI output would be
  fabricated footage of a real scientific event — and on a science channel, "is this even
  real?" comments are fatal. Stylized reads as deliberate art direction and stays consistent.
- **Never generate text.** AI renders letters badly and differently every time. Every label,
  arrow and number goes on in DaVinci over a clean plate.

## 4. WHAT TO CREATE OR DOWNLOAD FIRST

Strict order. Each step feeds the next.

**FIRST — the voiceover (this phase).** Everything else gets cut to it. Building visuals before
the voice is the classic beginner mistake in this format: you end up with lovely shots that
don't fit the read.

**THEN, in Phase 2 (not yet):**
1. **Stock + NASA plates** — shots 09, 23, and the map bases for 03, 06, 29. Free, instant, no
   generation. Search NASA Scientific Visualization Studio, NASA Earth Observatory, Pexels,
   Pixabay. Terms: *Antarctica aerial, ice sheet, glacier calving, polar plateau*.
2. **IMG 07 first, and get it right** — it is the plate for shots 07, 08, 24 and 25. One good
   render covers four shots. Then IMG 12 (reused in 13). Then the remaining five.
3. **The 5 AI videos, spread over ~3 days** on free daily allowances. Generate **VID 01 first** —
   it sets the look. Where a service accepts a reference image, feed a frame from VID 01 into the
   others to hold the palette.
4. **Music and ambience** — YouTube Audio Library, Pixabay Music, Freesound. One music bed, wind
   ambience for Acts 1–2, underwater ambience for Act 3.

> **Worth knowing:** only 2 shots are stock in this plan, and 16 are graphics you build yourself —
> that is the biggest block of work. If you want to cut that down, look for real public-domain
> footage for shots 10 and 11 as well (Antarctic field camps and hot-water drilling do exist in
> NSF and NASA archives). Every shot you find as stock is a shot you don't have to build.

## 6. GENERATE THE VOICEOVER

### Install (one time)
```bash
pip install edge-tts
```
No account. No API key. No card. Neural voices, no monthly cap.

### Audition a voice
```bash
edge-tts --list-voices | grep en-GB
```
Trust that list over any name I give you — voice IDs change. `en-GB-RyanNeural` is a good
documentary read; `en-GB-SoniaNeural` if you want female. Test one line before doing all 30:
```bash
edge-tts --voice en-GB-RyanNeural --rate=-5% \
  --text "There's a hole in Antarctica. Two feet wide." --write-media test.mp3
```

### Generate all 30
```bash
bash scripts/generate_vo.sh ~/Videos/under-the-ice/01_vo
```
Edit `VOICE` at the top of that script first if you preferred a different one.
**Lock that voice for the whole video, and for the channel.** Changing it later means redoing everything.

### Check the durations
```bash
bash scripts/check_durations.sh ~/Videos/under-the-ice/01_vo
```
Any file over **9.5s** gets flagged. Fix it by **shortening the words in `narration/blocks.txt`
and re-running** — never by speeding up the read. A rushed narrator is the fastest way to sound
like a low-effort channel.

## 7. BUILD THE SPINE IN DAVINCI RESOLVE FREE

The free version is not a trial. It includes Fusion (for your 16 graphics), the Color page, and
1080p export. Nothing else is needed.

### Create the project
1. Open Resolve → **New Project** → name it `under-the-ice`. Save it into `07_project/`.
2. **File → Project Settings → Master Settings**:
   - Timeline resolution **1920 x 1080**
   - Timeline frame rate **30** — set this *before* importing anything. It cannot be changed
     once media is on a timeline, and most free stock is 30fps.

### Import the voice
3. **Media** page (bottom bar). Drag your `01_vo` folder into the Media Pool.
4. Right-click in the Media Pool → **New Bin** → make bins: `VO`, `IMG`, `VID`, `STOCK`, `GFX`,
   `MUSIC`. Drop the 30 VO files into `VO`. Do this now — it costs two minutes and saves hours.

### Lay the spine
5. **Edit** page. Select all 30 VO files in order, drag them onto audio track **A1**.
6. Butt them end to end with no gaps. This is your spine — the entire video's timing now exists.
7. Play it through once, start to finish. **Listen for anything that sounds rushed or unclear.**
   Fixing a line now costs one command. Fixing it after you have built 30 visuals costs a day.

### Mark the blocks
8. Put the playhead at the start of each VO clip and press **M** to drop a marker. Thirty markers
   = thirty visual slots. When you place visuals in Phase 2, you cut to these.

### Set up the unification layer now (so you don't forget later)
9. **Effects → Toolbox → Effects → Adjustment Clip.** Drag it onto video track **V3**, stretched
   across the whole timeline. Leave it empty for now.
10. This single layer will later carry grain, a vignette and a cool tint across everything. It is
    what makes AI stills, AI video, NASA footage and your own graphics read as one production —
    and it matters more than the quality of any individual asset.

> Note: a few ResolveFX are Studio-only. For grain, the reliable free route is a **free grain
> overlay clip** (Pexels / Pixabay) dropped on V3 with its Composite Mode set to **Overlay** or
> **Soft Light** and opacity around 10–15%. For the vignette, use a circular **Power Window** on
> the Color page and pull the exposure down outside it. Both are free and version-proof.

### Save
11. **File → Save Project.** Resolve autosaves, but get in the habit.
